# Chatpane Shell themes

[Chatpane](https://github.com/kristofferR/Chatpane)'s built-in themes, but
chats keep their own Messenger colors. See
[#505](https://github.com/kristofferR/Chatpane/issues/505).

Themes are in [`themes/`](themes). Add one with **Settings → Appearance →
Add theme file…**.

To make your own, copy [`shell-template.css`](shell-template.css) and change
the colors.
